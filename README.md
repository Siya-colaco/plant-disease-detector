# 🌱 AI Plant Disease Detector

> An AI-powered web application that detects plant diseases from photos instantly.

-----

## 🌿 About The Project

*BotaniCure* is an intelligent plant disease detection web app built using HTML, CSS and JavaScript. Users can upload any plant or leaf photo and the AI will instantly analyze it and provide a complete diagnosis including disease name, severity level, confidence score, symptoms and treatment recommendations.

This project was built to help farmers, gardeners and plant lovers quickly identify and treat plant diseases using the power of Artificial Intelligence.

-----

## ✨ Features

- 📸 Upload any plant photo (JPG, PNG, WEBP)
- 🧠 AI analyzes the image in real-time
- 🌡️ Shows disease name and severity level
- 📊 Displays AI confidence score
- 💊 Provides treatment recommendations
- 🔍 Lists visual symptoms detected
- ⚡ Fast and easy to use interface

-----

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenRouter AI API
- REST API Integration
- VS Code
- Live Server

-----

## 🚀 How To Run

1. Clone this repository
1. Open plant_detector.html in VS Code
1. Get a free API key from [openrouter.ai](https://openrouter.ai)
1. Replace YOUR_API_KEY_HERE with your key in the code
1. Right click the file and select *“Open with Live Server”*
1. Upload a plant photo and click *Analyze!*

-----

## 📸 How It Works

1. User uploads a plant photo
1. Image is sent to AI vision model
1. AI analyzes the leaf for diseases
1. Results are displayed with disease name, severity, symptoms and treatments
